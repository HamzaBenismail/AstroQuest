# Art Credits

Every asset used in `public/art/` must be listed here with its source and license before it
ships. Never add an asset with an unknown license (CLAUDE.md §7.3).

**Phase 5 note:** no designer or sourced art assets were available for this project at
build time. Rather than ship empty boxes, every layer below is original, hand-written SVG
vector art, authored directly for this project (not copied, traced, generated from, or
based on any third-party image, font, or dataset). Because nothing was sourced externally,
there is no third-party license to track — only an explicit grant for this project's own
use. These are explicitly **placeholder-tier** visuals (§7.3): a designer can replace any
file below with final art of the same filename without touching any code.
