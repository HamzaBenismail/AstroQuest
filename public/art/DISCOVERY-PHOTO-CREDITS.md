# Discovery photograph credits — real source images, not AI-generated

These are six **existing photographic images retrieved by URL**, not illustrations generated by an image model. They illustrate real scientific work, but **are not necessarily photographs from the exact OSDR study represented by the discovery**. The matching study records remain identified by OSDR IDs internally in `src/data/discoveries.js`.

Each discovery card shows its photograph's agency/institution credit as visible text, **not as an outbound link**. This file preserves full image-source references for maintainers and reviewers. The app does not load new science API data during gameplay.

## Terms and accuracy

- NASA's media policy: https://www.nasa.gov/nasa-brand-center/images-and-media/. NASA encourages credit, prohibits implied endorsement, and flags third-party copyrighted images separately.
- Brookhaven's separate image licensing policy: https://www.bnl.gov/newsroom/image-use.php. The displayed caption must say **"Image courtesy of Brookhaven National Laboratory"**. Its reuse is subject to BNL's specific licensing terms; check that your educational distribution satisfies them, and seek permission when necessary before shipping or bundling that photograph.
- All six photos are **contextual illustrations of similar science**, not experimental evidence from the particular OSDR study. The game bonuses are fiction based on research themes, not new experiments performed by the game astronauts.
- The game uses the photo credits as plain text to satisfy the request for no outbound links in discovery cards. Source pages and original media URLs are preserved here.
- The game component initially attempts local media `public/art/discoveries/` (for an offline build) and falls back to the matching remote photo URL if the local file is missing. To create local copies on an internet-connected developer machine, run `node scripts/prefetch-discovery-photos.mjs --fetch`. This tool was **not** run successfully in the isolated build environment; no remote photographic bytes were bundled in this update ZIP. If you ship an offline-only version, run the downloader first and check each image, including rights.
